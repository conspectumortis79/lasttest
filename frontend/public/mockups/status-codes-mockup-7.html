Mockup 7 — Gantt-Balken
  • Jede Zeile ist ein Status-Code. Die Zeile hat volle Breite und repräsentiert die gesamte Laufzeit.
  • Die Zeile ist in farbige Segmente (Family-Farbe) und farblose Lücken aufgeteilt. Ein farbiges Segment = "der Code hat während dieses Zeitraums mindestens einmal gefeuert". Eine Lücke = "der Code war inaktiv".
  • Konkrete Beispiel-Daten:
    • 200: 0–10s aktiv, 10–20s inaktiv, 20–30s aktiv (zwei grüne Blöcke)
    • 429: 10–20s aktiv (Rate-Limit-Spike während der Ramp-Up-Phase)
    • 404: 0–3s aktiv (Endpunkt nicht gefunden, vermutlich Warm-up)
    • 502: 27–30s aktiv (Timeout beim Plateau)
  • Die Wand-Uhrzeit-X-Achse unter den Balken ist deckungsgleich mit dem Auslastungs-Graphen oben — wenn ein 5xx-Block genau in der Last-Spitze landet, sieht man das auf einen Blick.
  • Sortierung: nach Anzahl absteigend (200 zuerst). Optional: nach Erscheinen sortieren (welcher Code tauchte zuerst auf).
  • Bei einem Code, der nur einmal gefeuert hat, ist das Segment eine dünne vertikale Linie an der entsprechenden Position.
  • Live-Variante: die Segmente wachsen während des Laufs von links nach rechts — was sich nicht geändert hat, bleibt eingefroren.
